### Setup and Operation Instructions

1. **Install Samsung USB Drivers:** Driver Installation.
Download and run the official Samsung USB Driver package. Restart the PC after installation to establish proper COM port mapping.

*Verification:* Open **Windows Device Manager** and verify that your Samsung phone appears under **Ports (COM & LPT)** or **Universal Serial Bus controllers** when connected.


2. **Connect UMT Dongle & Run Setup:** Hardware Check.
Connect your UMT / UMT Pro hardware dongle into a USB port. Right-click `UMTSams.exe` or `SamsungToolV1.1.exe` and select **Run as Administrator**.

*Verification:* The UltimateSams main dashboard opens and displays connected card details alongside the log output window.


3. **Perform FRP or Flashing Operation:** Mode Selection & Service.
Select the appropriate tab (**Flasher**, **Tools**, or **Service**). Put the device into its designated connection mode (Download Mode via Vol Down + Power while plugging USB, or MTP mode with `*#0*#` dialed on the Emergency screen) and click the target execution button (e.g., **Reset FRP** or **Flash**).

*Verification:* Check the main status panel until it logs `Operation Finished: OK`.
